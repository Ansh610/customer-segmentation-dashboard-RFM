# 📊 Customer Segmentation Dashboard using RFM Analysis & K-Means Clustering

An interactive **Customer Segmentation Dashboard** built using **Python, Machine Learning, and Streamlit** to analyze customer purchasing behavior through **RFM (Recency, Frequency, Monetary) Analysis** and **K-Means Clustering**.

The project helps businesses identify high-value customers, understand purchasing patterns, and support data-driven marketing and customer retention strategies through interactive visualizations.

---

# 📸 Dashboard Preview

![Dashboard Overview](images/dashboard-overview.png)

The Streamlit dashboard provides an interactive interface to explore customer segments, key performance indicators, and purchasing behavior using dynamic filters and visual analytics.

---

# 🎯 Business Problem

Businesses often have thousands of customers with different purchasing behaviors. Treating every customer the same results in inefficient marketing campaigns and lower customer retention.

This project segments customers based on their purchase history, enabling businesses to:

- Identify high-value customers
- Recognize at-risk customers
- Improve customer retention
- Support personalized marketing campaigns
- Analyze customer purchasing behavior

---

# 🎯 Objectives

- Perform customer segmentation using purchasing behavior
- Apply RFM (Recency, Frequency, Monetary) Analysis
- Build Machine Learning customer clusters using K-Means
- Create an interactive Streamlit analytics dashboard
- Generate business insights from customer data
